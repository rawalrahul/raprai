# Playbook: Open Application by Name
TASK_TYPE: computer_use
STATUS: active
SUCCESS_RATE: 0.96

## Steps
1. Press Win key or Win+S to open search
2. Type app name
3. Wait for search results (take screenshot)
4. Press Enter to open top result — OR click the app icon in results
5. Wait for app window to appear (take screenshot, verify title bar)

## Fallback
- If search doesn't find it: check Desktop, taskbar, Start menu manually
- If already open: bring to front via taskbar click

## Notes
- Win+S is faster than clicking Start button
- Verify app opened before proceeding
