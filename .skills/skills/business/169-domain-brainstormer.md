# Domain Brainstormer: Creative Generation & Availability Strategy

## Purpose
Systematically generate domain names using proven brainstorming techniques (portmanteau, metaphor, acronym), evaluate against naming criteria (short, pronounceable, memorable), check availability across TLDs (.com, .io, .dev, .ai), and verify brand safety (no unintended meanings in other languages, no trademark conflicts). Use this to find the perfect domain in 2-3 hours instead of weeks of frustration.

## When to Use / Do NOT use when
**USE WHEN:** Launching startup, building personal brand, creating new product, or rebranding company.
**DO NOT:** Use for projects with existing brand guidelines; don't settle for poor-fit domain just because .com is taken.

## Instructions

### Step 1: Define Your Brand in 3 Words
**Start with clarity** (shapes idea generation):

```
Brand Definition Exercise:
Answer each:

1. What does your company DO?
   (Examples: Email marketing, meditation app, SEO tool)
   Your answer: ________________

2. What feeling/emotion should users have?
   (Examples: confident, calm, energized, safe)
   Your answer: ________________

3. Who is the user?
   (Examples: busy founders, stressed workers, high-schoolers)
   Your answer: ________________

This guides name selection toward:
"Simple name" (not complex), "Action-oriented" (not boring),
"Professional but approachable" (not corporate or too casual)
```

### Step 2: Brainstorm Using 7 Techniques
**Technique 1: Portmanteau** (Combine 2-3 words)

```
Formula: [Word1] + [Word2] = New word

Examples:
- Email + Automate = Emailmate (no, too generic)
- Flow + Logic = Flowgic (better, tech sounds cool)
- Dispatch + Logic = Dislogic (technical, strong)
- Simple + Seamless = Semless (too similar to "seamless")
- Rapid + Response = Rapids (short, clear)

Process:
1. List 10 relevant words (email, flow, signal, swift, etc)
2. Combine pairs (try 5-7 combinations)
3. Filter: Pronounceable? Unique? Under 15 characters?

Results:
✓ Rapidsend (email platform)
✓ Flowchart (project management)
✓ Dislogic (analytics)
✗ Eamilow (not pronounceable)
```

**Technique 2: Acronym** (First letters of phrase)

```
Formula: [Word1][Word2][Word3] = Acronym

Examples (Real):
- "Asynchronous JavaScript and XML" = AJAX
- "Application Programming Interface" = API
- "Situation Normal All Fouled Up" = SNAFU
- "Self Contained Underwater Breathing Apparatus" = SCUBA

Process:
1. Write your value prop as phrase: "Email Marketing for Startups"
2. Take first letters: E-M-F-S
3. Rearrange if possible: SMEF? FEST? SERF?
4. Make pronounceable

Results for "Email Marketing Automation for Teams":
✓ EMAT (not pronounceable)
✓ TEAM (perfect! Even better because matches value)
✓ MEAT (hmm, negative connotations)
✓ MATE (friendly, short, 4 letters)

Better result: "TEAM" or "MATE" (brand it as Team or Mate)
```

### Step 4: Check Availability Across TLDs
**Priority Strategy**:

```
Tier 1 - .com (Default, 90% of market expects)
- If available: Take it immediately
- Cost: $8-15/year
- Brand trust: Highest

Tier 2 - Industry-specific (If .com taken, strong alternatives)
- .io (tech/startups, $30/year)
- .dev (developers, $15/year)
- .ai (AI-focused, $50/year, trendy)
- .co (startup-friendly alternative to .com, $20/year)
- .app (app-focused, $20/year)

Tier 3 - Niche TLDs
- .tech (tech companies, $30/year)
- .tools (tooling companies, $20/year)
- .space (creative/new projects, $30/year)
- .lab (experimental, $20/year)

Tier 4 - Country codes (Only if geographic focus)
- .uk, .ca, .au, .de (for specific countries)

Strategy:
1. Check [name].com first (most important)
2. If taken, check: .io, .co, .dev, .ai (in that order)
3. Never use hyphens (signals compromise, hard to market)
4. Never use numbers (similarly bad)
5. Compromise on .io if .com taken? Yes, only if .io is clean

```

```
- French: Zoom (English loan word, okay)

```

**Quick Safety Check** (Ask these):

```
1. Does the name sound like anything rude/negative?
   - Test with friends, not just yourself

2. In any language you know, does it have negative meaning?
   - Use Google Translate to spot-check top 10 languages

3. Is it trademarked already?
   - Search USPTO (patents.google.com)
   - Search company name in Google
   - Search in your country's trademark database

4. Is it associated with a person/character already?
   - Famous person named ZOOMA?
   - Character from show/movie?
   - Search "[name] person" or "[name] character"

5. Any SEO conflicts?
   - Will it be hard to rank for?
   - Are there dominant competitors with same name?

Example:
Name: Clarity
- Rude meaning? No ✓
- Negative meaning in other languages? No ✓
- Trademarked? YES ✗ (Multiple "Clarity" companies exist)
- Person/character? Maybe (Clarity from DC Comics)
- SEO conflicts? YES (Hard to rank, too generic)

Verdict: Safe but not unique, trademark challenges
```

### Step 6: Trademark Search
**Basic Trademark Check**:

```
Tool 1: USPTO Trademark Search (US)
- Visit: uspto.gov/trademarks
- Search exact name
- Shows registered, applied, abandoned marks
- Coverage: United States only

Tool 2: WIPO Global Brand Database
- Visit: wipo.int/branddb
- International trademark search
- Coverage: 190+ countries
- Most comprehensive

Tool 3: Google Trademark Search
- Visit: google.com/patents (has trademark section)
- Quick check for common trademarks

Process:
1. Search exact name: "ZOOMA"
2. Check all formats: "Zooma", "ZOOMA", "zooma"
3. Look for status:
   - "Active" = Currently protected (can't use)
   - "Abandoned" = No longer protected (probably safe)
   - "Application" = Pending (risky, might be denied)
4. Check class relevance:
   - Class 35: Advertising/marketing services
   - Class 42: Software/technology services
   - If trademark is in different class (e.g., clothing), less risky

Results Example:
Name: "SIGNAL"
- Found: Signal Protocol Foundation (Class 42, Software) - ACTIVE
- Found: ESPN Sports Signal (Class 35-42) - ACTIVE
- Conclusion: TOO RISKY, many strong trademarks

Name: "ZOOMA"
- Found: None
- Conclusion: AVAILABLE for trademark

Recommendation: Hire trademark attorney ($300-800) to check and file
               before heavy marketing (protects brand)
```

1. **50+ names generated**: Diversity in approach and options
2. **Scoring completed objectively**: Not gut-feel, but criteria-based

7. **Budget understanding**: Knows cost of domain, trademark, maintenance

## Common Mistakes

1. **Falling in love with first name**: Generate 50, then choose. Not just one brainstorm session.

2. **Skipping .com availability check**: Committing to name without checking leads to wasted brainstorming.

3. **Ignoring trademark research**: Launching brand with existing trademark = legal problems.

4. **Using hyphens or numbers**: "my-company" and "company2" are hard to market, signal compromise.

5. **Choosing too generic**: "Email" or "Clarity" are common, hard to rank for in SEO, trademark issues.

6. **Not checking cross-language meanings**: "Paxo" means something rude in another language (hypothetically), damages brand internationally.

7. **Settling for .io without justification**: .io is 30% more expensive and has lower brand trust for non-tech companies.

## Anti-Patterns

1. **Death by options**: Generating 200 names, then paralyzed by choice. Limit brainstorm to 50-75, then score ruthlessly.

2. **Skipping trademark filing**: Waiting until "later" means someone else files it. File within 6 months of launch.

3. **Compromising too early**: "Well, .com is taken, but .net is available" → 5 years later, .com company gets customers confused.

4. **Brand pivots due to domain**: Starting with wrong brand because domain was available, not because it's right. Choose brand first, find domain.

5. **Not parking backup domains**: Even if zooma.io isn't your primary, park it ($12/year) to prevent competitors using it.

6. **Ignoring social handle availability**: Purchasing domain.com but @domain is taken on Twitter/Instagram. Check all before committing.
