## RAPR AI 2.0.3

### More AIs, and a catalog to find them
**New AIs:** Copilot CLI, OpenCode, Droid (Factory) and Qwen Code. RAPR checked each one's command-line options against its current version.

**Claude Code and Codex on free local models.** Two new choices, **Claude Code (Ollama)** and **Codex (Ollama)**, run those agents on a model running in Ollama on your computer. They need no subscription and work offline. Pick the model with `/model`. Local models are slower and weaker than the paid ones and need a strong computer. For safety, Claude Code is only ever pointed at Ollama on this computer.

**AI catalog.** Settings → AI Integrations now lists every supported AI with a one-line description, its install command (with a Copy button), a link to its docs, and **▶ Start session** once it's ready. The "New session" menu shows only the AIs that are set up, plus **➕ Add more AIs…**, which opens the catalog.

### Start AIs with @mentions
Start a message with `@codex`, `@claude`, `@antigravity` (or any AI's name) in the app, Telegram or WhatsApp:
- **Nothing open:** RAPR starts that AI in your current folder and gives it the rest of your message.
- **Already working with an AI in the same folder** (say Claude), and you write `@codex review this`: your session turns into a group chat with Claude and Codex. The last few messages come along so Codex knows the context. Mention another AI later and it joins the same group.
- **You've moved to another folder since** the AI's last task: RAPR starts a separate session there instead.
- **Inside a group chat**, `@` an AI that isn't in it yet and it joins.

Only mentions at the very start of a message count, and only real AI names, so "ask @codex later" or an email address is just text.
