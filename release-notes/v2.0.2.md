## RAPR AI 2.0.2

### Antigravity works
Google stopped the Gemini command-line tool for personal Google accounts (free, AI Pro and Ultra) in June 2026. Its replacement is the **Antigravity CLI** (`agy`), and RAPR now works with it:

- Install Antigravity CLI and sign in by running `agy` once. Then choose **🪐 Antigravity** in RAPR.
- Pick its model with `/model` in a chat, or 🎯 Model in Telegram. The list comes from `agy models`, so new models appear when Antigravity updates (for example Gemini 3.8 Flash, Gemini 3.1 Pro, Claude Sonnet 4.6).
- RAPR shows Antigravity's steps live while it works.
- Very long requests are handed to Antigravity as a file, because Windows limits how long a command can be.

**Gemini.** If the old Gemini tool refuses your personal account, RAPR now says so and points you to Antigravity. The Gemini tool still works with a Gemini API key.

**Antigravity by default.** Setup now offers Antigravity instead of the Gemini CLI. Gemini only appears in RAPR's AI lists if the Gemini CLI is still installed on that computer. In Telegram, start an Antigravity session with `/antigravity` (or `/agy`).

### Fixes
**Codex works with current Codex versions.** Codex 0.16x removed an option RAPR was using (`--full-auto`), so every Codex request failed with "unexpected argument". RAPR now uses the current equivalent, which older Codex versions also accept.

**Deleting a group chat closes the AIs it started.** When you pick AIs for a group chat, RAPR starts a session for each. Deleting the group now closes those sessions too. Sessions you picked yourself are kept.

**The 🗑️ and ⏸ buttons act on their own session.** In the session list they used to act on the selected session instead of the one you clicked.

**Discarding a bake-off stops its AIs.** AIs still working when you discard a bake-off are now stopped.
