## RAPR AI 2.0.1

A fixes release for the AIs you connect with an API key or a command-line tool. Everything from 2.0.0 is unchanged.

### API AIs work again
**Groq and OpenRouter.** Requests were refused with "error code: 1010", because the services' firewall blocks requests that don't say which app is calling. RAPR now identifies itself, so they answer.

**GitHub Models.** GitHub retired the old address, so every request failed with "Name or service not known". RAPR now uses the new one. Models have new names such as `openai/gpt-4o-mini`; the old short names still work. Your token needs the **Models: read** permission (fine-grained token).

**Up-to-date models.** Groq's Llama 3 models were retired, so Groq now starts with `openai/gpt-oss-120b`. OpenRouter now starts with `openrouter/free`, which picks a free model, so it works without credits. You can choose any other model as before.

### Command-line AIs
**Open Interpreter** gets your whole message (it was started with an option it doesn't have).
**Amazon Q / Kiro CLI** answers without opening an interactive chat.
**Cursor** no longer stops at "Workspace Trust Required" in a new folder.
**Aider** uses its current "yes to everything" option.

### Fixes
**Pick the model for Claude, Codex and Gemini.** Type `/model` in a chat (app or Telegram) to see the models, and `/model <name>` to switch. In Telegram you can also tap 🎯 Model and choose. The list comes from the Claude, Codex and Gemini tools installed on your computer, so new models appear when those tools update. Claude shows its "latest model" names (like `opus` and `sonnet`), Gemini shows `auto`, `pro`, `flash` and `flash-lite`, and Codex shows the models in its own list.

**Your model choice is remembered.** The model you pick for Claude, Codex or Gemini with `/model <name>` is now kept in your data folder, so updating RAPR no longer forgets it.

**No more "Could not save last state" warnings** in the log. Your sessions are saved properly for resuming.
